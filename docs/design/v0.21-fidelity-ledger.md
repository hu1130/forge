# Forge v0.21.1 fidelity ledger

Reference direction: OpenWork-inspired light desktop workspace, interpreted for Forge's existing task, Diff, Git, terminal, Skill, MCP, provider, tenant, and backup capabilities.

## Main workbench

- Composition: matched the three-part desktop shell with a persistent project/task rail, a conversation workspace, and a dedicated inspector.
- Hierarchy: matched a quiet workspace breadcrumb, prominent task title, readable turn blocks, and an anchored composer.
- Primary actions: matched OpenWork's deep navy-black `#011627` action treatment while keeping approval and model choices inside the composer.
- Inspector: preserved Forge's real Changes, Git, and PowerShell views in the right rail instead of adding placeholder panels.
- Palette: replaced the previous blue-purple product wash with white, slate-gray, and near-black surfaces; green, amber, and red remain reserved for semantic states.
- Density: kept the reference's restrained borders, pale neutral surfaces, rounded panels, and large uninterrupted reading area.

## Settings

- Composition: matched the reference's application rail, grouped settings navigation, and wide configuration canvas.
- Grouping: separated workbench behavior, capabilities, and system/cloud controls so existing Forge settings remain discoverable.
- Controls: default provider, approval policy, inspector behavior, density, and reduced motion are real persisted settings.
- Color hierarchy: settings selection, switches, icon wells, focus rings, and primary actions now use the same neutral OpenWork color system without residual purple accents.
- Capability fidelity: provider keys, marketplace, Skills, MCP, runtime, cloud sync, and encrypted backup reuse their existing live flows.
- Truthfulness: cloud-only sections appear only for authenticated cloud sessions; no Automations, Apps, or update controls are shown before those features exist.

## QA evidence

- Concept images were inspected at original size: workbench `1586x992`, settings `1585x992`.
- Implemented captures were inspected at original size: workbench and settings `1920x1020`.
- Native sizes differ because the Windows Electron capture inherits the host display scale and available work area. Layout relationships were therefore compared at original image detail rather than by pixel overlay.
- Browser checks covered the main shell, all settings destinations, preference persistence, appearance state, and console errors.
