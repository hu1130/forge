## v0.4.1 structural direction

The accepted direction replaces the previous three-column skin with a full-height graphite navigation cockpit, a white workspace toolbar that does not span the sidebar, an open mist-gray conversation canvas, a right-aligned pale-blue user request, and a borderless Forge result with one collapsed execution-process disclosure. The bright code inspector remains on the right, with the terminal available from its lower dock. Use Chinese production UI copy, 13 px minimum body text, 6–8 px radii, cobalt selection accents, and status colors only for meaning. Avoid beige, a full-width dark top bar, stacked message cards, timeline connectors, gradients, glass effects, decorative art, fake metrics, and invented controls.

For settings, keep the graphite primary navigation visible and replace the centered modal with a full-height workspace surface. Add a dark secondary settings navigation for 模型提供商, 扩展市场, Skills, MCP 服务, 运行时, and 工作区. Render the real marketplace catalog as open table-like rows with name, type, installation state, and actions, while retaining search, filters, scope selection, refresh, details, install, update, and uninstall behavior. On narrow windows, rows may stack to preserve readability.
